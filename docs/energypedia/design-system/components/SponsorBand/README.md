# SponsorBand

Pas działu sponsorowanego z nazwą działu, logo partnera i linkiem „Jak zarabiamy”.

- Partner działu nie ma wpływu na treść; link „Jak zarabiamy” jest obowiązkowy.
- Logo partnera w polu 120×40 px, bez animacji; konsument przekazuje je jako `logo` (element `img` z opisem alternatywnym).
- Konsument podaje: `title`, `subtitle`, `logo`, `disclosureHref`, opcjonalnie `partnerLabel` („Partner działu”, „Partner Barometru”, „Partner regionu”).
