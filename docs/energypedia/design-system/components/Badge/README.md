# Badge

Krótka etykieta stanu (1–3 słowa) przy tytule karty.

- `status` (`status-bg` / `status-ink`): stan sprawy w trackerze („Przed decyzją URE”, „Projekt ustawy”, „Po wecie”) i dostępność („Od I kw. 2027”).
- `partner`: oznaczenie treści płatnej; zawsze ze słowami „Materiał partnera” lub „Reklama”.
- `accent`: nowość redakcyjna; `neutral`: archiwum, treść nieaktualna.
- Kolor nigdy nie niesie znaczenia sam – zawsze jest słowo.
