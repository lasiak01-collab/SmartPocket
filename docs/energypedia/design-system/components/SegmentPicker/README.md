# SegmentPicker

Wybór segmentu odbiorcy (Dom, Mikrofirma, Średnia firma, Duża firma i samorząd), który zmienia polecane treści.

- Zawsze cztery segmenty w tej kolejności; nazwy jak w treściach redakcyjnych.
- Wybór zapisuj tylko w pamięci przeglądarki (preferencja funkcjonalna) i nie używaj go do profilowania reklam.
- `compact` (siatka 2×2) na telefonie; zwykły rząd kart na komputerze.
- Konsument podaje: `options` `[{id, name, description}]`, `value` + `onChange` (sterowany) albo `defaultValue`, `label`.
