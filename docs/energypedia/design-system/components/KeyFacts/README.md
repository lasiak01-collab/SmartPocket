# KeyFacts

Blok „W skrócie” na początku artykułu: krótka odpowiedź (cytowalna przez Google i asystentów AI) i do trzech kluczowych liczb ze słupkami w kształcie słupków sygnetu.

- Stawiaj tuż pod nagłówkiem artykułu (tytuł, lead, autor), przed pierwszym śródtytułem. Jeden blok na stronę.
- `summary`: 1–2 zdania, samodzielna odpowiedź na pytanie z tytułu, bez „jak wspomniano”.
- `facts`: 0–3 liczby. `weight` (0–1) ustawia długość słupka i powinien oddawać proporcję między liczbami (np. 14 dni → 0,24; 30 dni → 0,52; 12 mies. → 1). Tylko jedna liczba w `tone="accent"`.
- `meta`: data i sposób weryfikacji („Sprawdzone z ustawą · 21.10.2026”); `footnote`: jedna linia z najważniejszym zastrzeżeniem lub linkiem do wzoru/narzędzia.
- Bez ramki, tła i kolorowego paska z boku — blok wyróżnia linia redakcyjna `ink` i typografia. Nie opakowuj go w kartę.
- Gdy nie ma sensownych liczb, pomiń `facts` — zostaje sama odpowiedź.
