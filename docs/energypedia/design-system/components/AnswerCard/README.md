# AnswerCard

Karta odpowiedzi AI z pytaniem, odpowiedzią, listą źródeł i zastrzeżeniem.

- Zawsze pokazuj źródła (co najmniej jedno: hasło lub poradnik Energypedii i źródło pierwotne, np. decyzję URE) oraz zastrzeżenie o AI – wymaga tego polityka redakcyjna i AI Act.
- Odpowiedź zaczyna się od zdania-odpowiedzi; liczby z jednostką, datą i informacją netto/brutto.
- Konsument podaje: `question`, `answer`, `sources` `[{label, href}]`; `kicker` i `disclaimer` tylko w uzgodnionych wyjątkach.
- Nie używaj karty do treści redakcyjnych pisanych przez człowieka – do tego służy artykuł.
