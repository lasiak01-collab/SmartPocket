# ContentCard

Karta odsyłająca do artykułu, poradnika, hasła lub wzoru pisma — albo do oznaczonego materiału partnera.

- `kind` to typ treści WERSALIKAMI („PORADNIK”, „ANALIZA DANYCH”, „WZÓR PISMA”, „PRZEWODNIK”).
- `partner` przełącza kartę na tło `partner-bg`, przerywane obramowanie, etykietę „MATERIAŁ PARTNERA · nazwa” i `rel="sponsored"`. Nigdy nie mieszaj materiału partnera z sekcją „Powiązane” redakcji; maksymalnie 1 karta partnera w rzędzie.
- Konsument podaje: `title`, `kind`, opcjonalnie `lead`, `href`, `partner`, `partnerName`.
