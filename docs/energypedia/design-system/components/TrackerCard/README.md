# TrackerCard

Karta tematu „na bieżąco” ze stanem sprawy i datą ostatniej aktualizacji.

- Status to etap faktyczny („Przed decyzją URE”, „Projekt ustawy”, „Uchwalona”, „Po wecie”, „Obowiązuje od …”), ustalany z radarem Prawnika.
- Data aktualizacji jest obowiązkowa (dzień i godzina); nie zmieniaj jej bez istotnej zmiany treści.
- Konsument podaje: `status`, `title`, `description`, `updated`, `href`.
