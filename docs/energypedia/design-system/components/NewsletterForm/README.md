# NewsletterForm

Pas zapisu do newslettera „Energia w 5 minut” na powierzchni `navy`.

- Jedno pole (e-mail), etykieta zawsze widoczna, informacja o wypisaniu i link do polityki prywatności.
- Po wysłaniu pokazuje komunikat o potwierdzeniu adresu (double opt-in); klauzule zgód zatwierdza Prawnik.
- Konsument podaje: `id`, `onSubmit(email)`, opcjonalnie `title`, `description`, `privacyHref`.
- Na stronie jeden taki pas; w kolumnie bocznej można użyć wersji skróconej tej samej treści.
