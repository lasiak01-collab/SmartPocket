# FaqList

Lista pytań z krótką odpowiedzią, każde prowadzi do pełnego tekstu.

- Pytania w języku odbiorcy (tak, jak wpisuje je w wyszukiwarkę), odpowiedź w jednym–dwóch zdaniach.
- Na stronie artykułu ta sama treść trafia do danych strukturalnych FAQ.
- Konsument podaje: `items` `[{question, answer, href}]`, 3–8 pozycji.
