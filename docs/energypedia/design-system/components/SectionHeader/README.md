# SectionHeader

Nagłówek sekcji strony (H2) z opcjonalnym nadtytułem, opisem, kropką danych na żywo i linkiem „więcej”.

- `live` dodaj tylko, gdy sekcja pokazuje dane aktualizowane automatycznie (np. „Energia dziś”).
- `eyebrow` pisz WERSALIKAMI tylko przez komponent (styl `label`); treść podawaj normalnie.
- Konsument podaje: `title`, opcjonalnie `eyebrow`, `description`, `action` `{label, href}`, `id` (do `aria-labelledby` sekcji), `level`.
