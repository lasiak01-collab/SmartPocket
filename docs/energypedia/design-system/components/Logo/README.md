# Logo

Znak (kafel z błyskawicą) i logotyp „energypedia.pl” składany na żywo krojem `display`.

- Używaj w nagłówku (`size="md"`, z `href` do strony głównej) i w stopce (`size="sm"`).
- Na powierzchni `navy` używaj `tone="inverse"` (kafel `volt`, błyskawica `on-volt`, napis `on-navy`).
- W ciemnym motywie znak sam się odwraca (tokeny `logo-tile`, `logo-bolt`), żeby był widoczny na `bg`.
- Konsument podaje: `href` (opcjonalnie), `tone`, `size`.
- Nie zmieniaj proporcji, kolorów ani kroju; nie umieszczaj logo na zdjęciach. Pliki SVG samego znaku są w grupie zasobów Logos.
